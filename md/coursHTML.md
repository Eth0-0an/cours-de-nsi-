### Le langage html 

1. HTML

HyperText Markup Language *langage de balise hypertext*

un fichier `.html` est un fichier de texte(comme le markdownpar exemple).On ouvre un fichier de 2 façon:
- le développeur => avec un éditeur de code (ex: VisualStudioCode)
- l'utilisateur => avec un navigateur (ex: firefox)
