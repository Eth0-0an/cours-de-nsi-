### Le langage html 

1. HTML

HyperText Markup Language *langage de balise hypertext*

un fichier `.html` est un fichier de texte(comme le markdownpar exemple).On ouvre un fichier de 2 façon:
- le développeur => avec un éditeur de code (ex: VisualStudioCode)
- l'utilisateur => avec un navigateur (ex: firefox)

le plus souvent les balises html sont en couple (ouvrante/fermante)mais il existe aussi des blises *orpheline*:
- `<Mabalise></Mabalise>`
- `<Mabalise>`

La structure minimale d'une page webest:

```html
<!DOCTYPE html>
<html>
<head></head>
<body></body>
</html>
```

le site de référence pour les language du web est le site du développeur de Mozilla.
[https://developer.mozilla.org/fr/docs/Web/HTML/Reference/Elements](https://developer.mozilla.org/fr/docs/Web/HTML/Reference/Elements)
